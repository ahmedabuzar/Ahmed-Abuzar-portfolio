# Ahmed Abuzar — Personal Portfolio (abuzar.fyi)

This is the repository for my personal portfolio website hosted at [abuzar.fyi](https://abuzar.fyi).

## 🌟 Features
- **Modern Dark/Light Aesthetics**: Inspired by sleek terminal & obsidian UI design.
- **Interactive Data Showcase**: Selected analytics case studies with live project links.
- **Custom Cursor & Micro-Interactions**: Smooth hover effects, preloader, and pixel dissolve animations.
- **SEO & Performance Optimized**: Structured JSON-LD schema, open graph meta tags, and responsive layout.

## 🛠️ Built With
- **HTML5 & Vanilla CSS3**
- **JavaScript (ES6+)**
- **Google Fonts** (Outfit, Plus Jakarta Sans, Space Mono)
- **Vercel** deployment
